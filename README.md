# Proyecto: React Native Animated Intermedio

- **_npx @react-native-community/cli init nombreProyecto_**

## Herramientas y/o Tecnologías

- React
- Animated
  - Es una _API_ para crear animaciones con _React Native_.
  - Puedes crear cualquier tipo de animaciones que se verán de forma fluida y ligera.
  - Es una _API_ bastante extensa y con poca documentación.
  - **MÉTODOS**
    - _Animtated.timming()_: Animación basaa en tiempo.
    - _Animtated.decay()_: La animación inicia a cierta velocidad pero se va deteniendo.
    - _Animtated.spring()_: Se le conoce como un _spring_ que detecta la velocidad para crear animaciones que llegan a un valor (_toValue_).
    - _Animtated.parallel()_: Inicia un _Array_ de animaciones al mismo tiempo.
    - _Animtated.sequence()_: Una serie de animaciones donde al terminar una inicia la otra.
